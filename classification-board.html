自由分類與比較

觀察素材、建立分類、說明依據，並比較不同分類方式。可獨立操作，也可編排為 Course Node 並加入平行活動群組。

活動設定

獨立分類 Session

先在首頁完成 Supabase Publishable key 設定。教師可建立獨立分類 Session；這裡不會影響既有 Course 節點。

分類素材

圖片目前使用外部 HTTPS URL；不會將影像原始資料放入分類答案。

教師預設類別

指定分類使用這些類別；預設類別僅供「指定分類」使用；自由分類由學生自行建立類別，不預設唯一正確答案。

待分類素材

可以點選素材指定類別，桌面也可以將素材拖曳至類別卡片。

分類板

全班匿名分類成果

教師公布後才會顯示其他人的成果。

學生提交成果｜分類明細與比較

只比較素材歸屬與分類理由，不將不同類別名稱自動判定為錯誤。獨立 Session 可從雲端比較，小組與個人結果分別保存。
